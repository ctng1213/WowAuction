Proposal: the Status page's AI assistant card

Approved by the user, 2026-11-08 (option B; SPEC §3.8.1) (plan docs/plans/mcp-server.md, MC3). The only new screen in the batch is one card on the Status page, next to the "AHSync app" card. Enable starts the assistant server inside AHSync and builds its market table in AHSync's memory: pressing it is your agreement to that memory, and the card says how much it is. Disable stops the server, closes its port and frees the memory at once. The choice is remembered across restarts. Claude connects through a small bridge, ahsync-mcp, that ships with AHSync. Paths and the memory figure below are examples; the card shows your install's and the measured amount.

1. Off (the default), and starting

What a new install shows. Nothing runs, nothing is held in memory, and nothing can be read.

Claude Desktop has no config file yet. Create it:

  1. Create this file: 
    C:\Users\you\AppData\Local\Packages\Claude_pzs8sxrjxfjjc\LocalCache\Roaming\Claude\claude_desktop_config.json
  2. Paste this into it and save. In Notepad, choose Save as type: All files, so it isn't saved as .txt. 
    {
  "mcpServers": {
    "ahsync": {
      "command": "C:\\Users\\you\\AppData\\Local\\Programs\\AHSync\\ahsync-mcp.exe"
    }
  }
}
  3. Quit Claude Desktop completely (right-click its icon by the clock, then Quit), then reopen it. In a new chat, AHSync is listed among Claude's connectors.
  4. Turn on web search in Claude, so it can check Wowhead for fishing levels and farming spots.

Once the file is right, the tab reads: ✓ Claude Desktop is set up for AHSync. If you just changed the file, quit Claude Desktop completely and reopen it. A file that already has mcpServers gets just the "ahsync" entry to add; an old entry gets the one to replace it with; a broken file gets the line it breaks on.

4. What doesn't change

No other page, tooltip or number moves. The card is the Status page's only new content; the server and the bridge have no screen. Enable and Disable go through the dashboard's token-checked POST, like the Risk tolerance dropdown, and the choice is stored with the app's other settings.

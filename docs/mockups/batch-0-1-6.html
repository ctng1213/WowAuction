3. Data coverage card for a cloud market: what the analysis has used (the user, 2026-11-07)

The heatmap keeps showing only the hours the daily analysis used (the user declined to have the hourly run extend it). A note under the card says how far the collection runs ahead of the analysis. Times are local (here Pacific: the daily run is 09:00 UTC = 01:00).

Data coveragelast 30 days · blizzard (cloud)
…heatmap and totals, as built (D99)…
Blizzard data collected to Sat 20:16 · analysed to Sat 06:00 · next analysis Sun 01:00

collected = the newest snapshot in the summary (prices, hourly); analysed = the end of the daily run's hours (rates, windows, patterns); next analysis = the next 09:00 UTC. A local market has no note. Engine-made text (engine/coverage.py), a new D row (D104). Lands in: dashboard.html (Status, States: data coverage).
